# Changelog

## 0.1.0

- Source-only pilot for optional Foundry resources, prompt-agent version creation/readback and exact-version one-shot structured responses.
- Explicit store=false, no conversation linkage, tools, background jobs or automatic retries; bounded input, schema, network response and output.
- Consumer-owned authentication, data minimization, policy, lifecycle, permissions and output storage; no runtime access to Microsoft 365 or solution storage is granted to the agent.
- Initial Exchange adoption and a second generic report-advisory adoption shape are documented. No hosted acceptance or signed component release is claimed.
